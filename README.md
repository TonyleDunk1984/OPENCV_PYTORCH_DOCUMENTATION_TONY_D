## 📊 Project Highlights

### Project 1: Image Classification (Cats, Dogs, Pandas)
In `tony-s-data-understanding-pipeline-check-ipynb.ipynb`, I implemented a complete deep learning workflow:
* **Data Preparation:** structured `Train`, `Valid`, and `Test` folders.
* **Data Loading:** Used `torchvision.datasets.ImageFolder` and `Subset` to create efficient data loaders for debugging.
* **Preprocessing:** Implemented image resizing, tensor conversion, and normalization using standard mean/std deviations.
* **Visualization:** Created custom visualization functions to inspect training samples and model predictions.
